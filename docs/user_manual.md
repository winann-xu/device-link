# DEVICE LINK 使用手册

> 版本: 1.0.0 | 平台: Windows 10/11 (64位) | 部署: 免安装便携版

## 1. 快速开始

### 1.1 安装
1. 解压 `DEVICE-LINK-v1.0.0.zip` 到任意目录
2. 双击 `DEVICE-LINK.exe` 即可运行
3. 系统托盘出现 DEVICE LINK 图标，说明启动成功

### 1.2 首次配置
1. 双击托盘图标或右键→打开主界面
2. 进入「设备管理」→ 添加需要监控的设备
3. 进入「告警配置」→ 配置通知通道（邮件/飞书/企业微信）
4. 返回「实时仪表盘」查看设备在线状态

## 2. 功能概览

### 2.1 实时仪表盘
- 按子系统分组展示所有设备卡片
- 在线(绿色) | 离线(红色) | 待定(黄色) | 维护(灰色)
- 支持搜索设备名/IP，快速筛选状态
- 每 2 秒自动刷新

### 2.2 设备管理
- **添加设备**：填写名称、IP、子系统、探测方式等
- **批量操作**：勾选多台设备→批量删除/启用/禁用/维护
- **CSV 导入**：下载模板→填写→导入（适合批量录入）
- **测试探测**：选中设备→点击测试→即时查看连通性

### 2.3 告警配置
- **邮件通道**：配置 SMTP 服务器、端口、账号密码、收件人
- **飞书通道**：填写机器人的 Webhook URL
- **企业微信通道**：填写群机器人的 Webhook URL
- **合并策略**：设置合并时间窗口（默认5分钟）
- **全局规则**：失败阈值N、恢复阈值M、冷却窗口、升级时间

### 2.4 历史统计
- 在线率概览：今日/本周/本月
- 离线排行榜：最近7天离线次数排名
- 告警日志：全部告警事件、支持确认和筛选

## 3. 探测与告警说明

### 3.1 探测策略
- **主探测**：ICMP ping（最快）
- **复核探测**：ping 失败时自动 TCP 端口复核
- **误报抑制**：连续失败 N 次（默认3次）才判定离线
- **恢复判定**：连续成功 M 次（默认2次）才通知恢复

### 3.2 告警合并
- 5 分钟窗口内的多条离线告警合并为一封摘要邮件
- 同子系统 ≥ 5 台设备同时离线 → 紧急绕过立即发送
- 恢复通知不参与合并（实时发送）

### 3.3 升级机制
- 离线告警未被确认超过15分钟 → 自动升级通知所有通道
- 确认告警后升级停止

## 4. 系统托盘

| 操作 | 行为 |
|------|------|
| 双击托盘图标 | 打开主界面 |
| 右键 → 打开主界面 | 显示窗口 |
| 右键 → 暂停监控 | 临时停止探测 |
| 右键 → 退出 | 确认后退出程序 |
| 点击窗口 × | 最小化到托盘（不退出） |

## 6. 常见问题

### Q: 设备明明在线但显示离线？
A: 检查 ICMP 是否被防火墙禁止。可启用 TCP 端口复核（设备配置中设置端口）。

### Q: 邮件通知发送失败？
A: 检查 SMTP 地址/端口/密码是否正确。QQ邮箱需使用授权码而非登录密码。

### Q: 如何批量添加设备？
A: 设备管理页面 → 导入CSV → 下载模板 → 按格式填写 → 导入。

### Q: 如何让程序开机自启？
A: 右键托盘图标 → 开机启动（勾选）→ 自动在启动文件夹创建快捷方式。

## 7. 技术支持

- 日志文件: `logs/device-link.log`
- 数据库: `data/device-link.db`（可用 SQLite 工具直接查看）
- 配置文件: `config/config.yaml`（修改后约2秒自动生效）
